# Evidence: real clients (16–17 Oct 2026, Keycloak 26.8.0)

Records of [real-clients/](../../real-clients/) as produced. The per-attempt HOME directories (the clients' own
configuration and the tokens they stored) are not included; nothing here holds a token. The proxy records keep
authorization codes in redirect URLs: single-use, already exchanged, issued by a lab realm that no longer exists.

- [RESULTS.md](RESULTS.md): one row per counted attempt, generated by `real-clients/summarize.py` from `runs/`.
- [stock-refusal-causes.txt](stock-refusal-causes.txt): every `LOGIN_ERROR` in the trial realm on stock Keycloak,
  paired with the executor log line of the same thread just before it (Keycloak logs `clientId=null` for these, because
  the document never became a client; the `client_id` of each request is in that attempt's `keycloak-requests.jsonl`).
- `runs/<utc>-<client>-<stock|ext>[-scoped]/`: `keycloak-requests.jsonl` (recording proxy), `keycloak-state.txt`
  (Keycloak events, CIMD clients in the realm), `keycloak-log.txt`, `mcp-requests.jsonl` (MCP server log),
  `browser.jsonl` (stand-in browser), `step-*.txt` (the client's own output), `config.txt`.

Attempt directories ending `-scoped` had `scope="openid"` in the MCP server's 401 challenge.

## Counted: 23 attempts (`runs/`)

codex, goose, hermes, opencode 1.2.27 and opencode 1.19.3 (`opencode19`): each on stock and ext, with and without the
scope hint (4 each). Copilot CLI, person in the loop: stock once, ext twice. The copilot stock attempt's MCP lines were
logged by an earlier session's server that still held the port; its `NOTE.md` explains this.
